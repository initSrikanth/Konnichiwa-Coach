# Konnichiwa Coach

A lightweight Japanese learning website for primary school students.

## Homepage (Phase 1)

- Original SVG Japanese garden with cherry blossoms, pond, bridge and softly glowing stone lanterns
- Four accessible activity entry points: Learn, Practise, Play and My Progress
- Responsive design for phones, tablets and desktop screens
- Subtle animation with reduced-motion accessibility support
- No login, no Firebase, no multiplayer, no background music and no backend
- Activities currently open clearly labelled **coming soon** screens (no false functionality claims)

## Technology

Plain HTML, CSS and JavaScript. All application code and illustrations are stored in this repository. The optional Google Fonts stylesheet improves typography but system and Georgia fonts work as fallbacks.

## Running locally

Open `index.html` in a browser, or serve the directory with any static HTTP server.

## GitHub Pages

In repository **Settings → Pages**, choose **Deploy from a branch**, select **main** and **/(root)**, then save. Once GitHub reports the deployment as published, the site will be available at `https://initsrikanth.github.io/Konnichiwa-Coach/`.
